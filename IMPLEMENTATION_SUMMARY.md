# ShipPlacementBoard - Улучшенное управление расстановкой кораблей

## Что было реализовано

### 1. ✅ Drag and Drop (Перетаскивание) для мыши и сенсорных экранов

#### Для мыши (Desktop):
- Корабли можно перетаскивать мышью по сетке
- Используется стандартный HTML5 Drag and Drop API
- Визуальная обратная связь при перетаскивании (белая граница вокруг корабля)
- Курсор меняется на `grab` при наведении и `grabbing` при перетаскивании

#### Для сенсорных экранов (Mobile/Tablet):
- Реализована поддержка touch-событий (`touchstart`, `touchmove`, `touchend`)
- Корабли можно перетаскивать пальцем по сетке
- Координаты автоматически вычисляются при отпускании пальца
- Работает как на iOS, так и на Android

#### Как работает:
1. **Начало перетаскивания**: нажимаешь на корабль (мышь или палец)
2. **Перемещение**: тащишь корабль по сетке
3. **Размещение**: отпускаешь на нужной клетке сетки
4. **Результат**: корабль размещается в новом положении или возвращается на место, если размещение невозможно

### 2. ✅ Альтернативный режим по клику (Click-based placement)

#### Функционал:
- **Клик по пустой клетке**: размещает выбранный корабль на эту клетку (если ориентация позволяет)
- **Клик по кораблю**: выбирает этот корабль или подготавливает его к перемещению
- **Предварительный выбор типа корабля**: кнопки выбора длины корабля (1, 2, 3, 4-палубный)

#### Как работает:
1. Выбираешь нужную длину корабля из кнопок сверху
2. Выбираешь ориентацию (горизонтально/вертикально)
3. Кликаешь на клетку сетки - корабль разместится там
4. Если размещение невозможно, появится сообщение об ошибке

### 3. ✅ Кнопка поворота корабля (Rotate Button)

#### Реализация:
- **Кнопка "Поворот"** в верхней части панели управления
- Показывает текущую ориентацию: "Горизонт" или "Вертикаль"
- Значок с вращающимся циклом (из lucide-react)
- При клике меняет ориентацию для выбранного корабля

#### Как работает:
1. Нажимаешь кнопку "Поворот"
2. Ориентация меняется с горизонтальной на вертикальную (и наоборот)
3. При следующем размещении корабль будет размещен с новой ориентацией

## Технические детали

### Новые функции в компоненте

#### `getGridCoordinateFromEvent(clientX, clientY)`
- Вычисляет координаты сетки из координат мыши/пальца
- Учитывает padding и gaps в CSS Grid
- Возвращает `{row, col}` или `null` если клик вне сетки

#### Обработчики для мыши:
- `handleDragStart`: Инициирует перетаскивание
- `handleDragOver`: Позволяет drop-событие
- `handleDrop`: Завершает перетаскивание и размещает корабль

#### Обработчики для сенсорных экранов:
- `handleTouchStart`: Начинает отслеживание касания
- `handleTouchMove`: Предотвращает скроллинг при касании
- `handleTouchEnd`: Вычисляет финальное положение и размещает корабль

### Новый подкомпонент `ShipPlacementGrid`
- Отделенный компонент для отрисовки сетки
- Обрабатывает клики по клеткам
- Визуально выделяет перетаскиваемый корабль

### Визуальные улучшения
- Добавлены hover-эффекты на кнопки
- Корабли при наведении показывают курсор `grab`
- При перетаскивании корабль подсвечивается белой границей
- Кнопки управления более отзывчивы

## Как использовать

### Способ 1: Drag and Drop
1. Выбери размер корабля
2. Выбери ориентацию кнопкой "Поворот"
3. Перетащи корабль со сторона на новое место

### Способ 2: Click-based
1. Выбери размер корабля
2. Выбери ориентацию кнопкой "Поворот"
3. Кликни на пустую клетку сетки
4. Корабль разместится

### Способ 3: Комбинированный
- Используй click для быстрого размещения новых кораблей
- Используй drag-and-drop для перемещения уже размещенных

## Тестирование

Рекомендуется протестировать:

1. **Мобильный (Touch)**
   - Открыть на смартфоне или планшете
   - Перетащить корабль пальцем
   - Кликнуть на клетку

2. **Desktop (Mouse)**
   - Перетащить мышью
   - Кликнуть на клетку
   - Нажать кнопку поворота

3. **Граничные случаи**
   - Перетаскивание корабля вне сетки (не должно разместиться)
   - Размещение корабля вне границ (должно отклониться)
   - Размещение на занятую клетку (должно отклониться)
   - Размещение рядом с другим кораблем (должно отклониться по правилам)
