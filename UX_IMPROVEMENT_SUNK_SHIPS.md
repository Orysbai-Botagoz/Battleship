# 🎨 UX Улучшение: Визуальная панель потопленных кораблей

## Описание

Заменена текстовая система счетчиков потопленных кораблей на красивую **визуальную панель со силуэтами кораблей**. Теперь игроки могут наглядно видеть, сколько кораблей каждого типа потоплено противником и у них самих.

---

## Что было раньше

```
┌─────────────────────────────┐
│ Потоплено у противника      │
├─────────────────────────────┤
│  4п: 1  │ 3п: 2 │ 2п: 0 │ 1п: 0 │
└─────────────────────────────┘
```

**Проблемы:**
- Просто текст, неинформативно
- Не ясно, сколько кораблей каждого типа вообще было
- Сложно быстро оценить состояние боя на глаз
- Минималистично, но неинтуитивно

---

## Что стало теперь

```
┌──────────────────────────────────────────┐
│ Потоплено у противника                   │
├──────────────────────────────────────────┤
│ 4п     ■ ■                               │
│ ─────  (1 красный = потоплен)            │
│        (1 серый = живой)                 │
│                                          │
│ 3п     ■ ■ ■  ▢ ▢ ▢                     │
│ ─────  (2 красные = потоплены)           │
│        (1 серый = живой)                 │
│                                          │
│ 2п     ■ ■  ▢ ▢ ▢                       │
│ ─────  (2 красные = потоплены)           │
│        (1 серый = живой)                 │
│                                          │
│ 1п     ■ ▢ ▢ ▢                          │
│ ─────  (1 красный = потоплен)            │
│        (3 серые = живые)                 │
└──────────────────────────────────────────┘

Каждый квадрат = палуба одного корабля
■ = красный (потоплен)
▢ = серый (еще на плаву)
```

**Преимущества:**
- ✅ Визуально интуитивно и понятно
- ✅ Четко видно количество кораблей каждого типа
- ✅ Видно, сколько потоплено vs сколько осталось
- ✅ Красивая визуализация с гладкой анимацией
- ✅ Компактна и хорошо смотрится на темной теме
- ✅ Размеры кораблей пропорциональны (4 ячейки, 3 ячейки, 2 ячейки, 1 ячейка)

## Технические детали

### Новый компонент: `SunkShipsPanel.tsx`

**Функциональность:**
- Отображает силуэты кораблей всех 4 типов
- Для каждого типа показывает: сколько потоплено / всего
- Каждый потопленный корабль закрашивается в красный цвет
- Живые корабли остаются серыми (полупрозрачные)
- Гладкая анимация перехода при потоплении корабля (transition-all duration-300)

**Структура компонента:**

```tsx
interface SunkShipsPanelProps {
  label: string;              // "Потоплено у противника" или "Потоплено у тебя"
  board: BoardState;          // BoardState с информацией о кораблях
}
```

**Компоненты:**

1. **ShipSilhouette** - отображает один кораблик
   - Параметры: `length` (1-4), `isSunk` (boolean)
   - Рендеринг: количество ячеек = длина корабля
   - Цвет: красный если потоплен, серый если живой
   - Стили: Tailwind CSS, гладкая анимация

2. **SunkShipsPanel** - главный компонент
   - Перебирает все типы кораблей (4, 3, 2, 1)
   - Подсчитывает потопленные корабли через `getSunkCount()`
   - Отображает каждый тип в отдельной строке

**Функции-помощники:**

```tsx
// Получить кол-во потопленных кораблей конкретной длины
const getSunkCount = (board: BoardState, length: ShipLength): number
```

## Визуальные характеристики

### Цветовая схема (Dark Theme)

| Элемент | Цвет | Tailwind класс |
|---------|------|---|
| Фон панели | Тёмный сланец | `bg-slate-900/70` |
| Бордер | Тёмный сланец | `border-slate-700` |
| Заголовок | Светлый сланец | `text-slate-100` |
| Живой корабль | Серый | `bg-slate-600 border-slate-500` |
| Потопленный корабль | Красный | `bg-red-500 border-red-400` |
| Счетчик (x/y) | Тусклый сланец | `text-slate-500` |

### Размеры

- **Каждая ячейка корабля:** 24px × 24px (`h-6 w-6`)
- **Промежуток между ячейками:** 4px (`gap-1`)
- **Промежуток между кораблями:** 8px (`gap-2`)
- **Отступы панели:** 16px (`p-4`)
- **Отступ между рядами:** 12px (`space-y-3`)

### Адаптивность

- **Мобильные устройства:** Полная ширина
- **Планшеты и выше:** 2 колонки (противник + ты)
- **Перенос строк:** Если много кораблей, могут переносить на следующую строку

## Поведение при изменении состояния

### При потоплении корабля

```
До:     1п: 2
        ▢ ▢ ▢ ▢

После:  1p: 3
        ■ ▢ ▢ ▢    (гладкая анимация цветового перехода)
```

**Анимация:**
- Дамо `transition-all duration-300` - плавное изменение цвета за 300ms
- Цвет меняется с `bg-slate-600` на `bg-red-500`
- Бордер также обновляется синхронно
